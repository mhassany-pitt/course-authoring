## Delivery URLs
Each activity item includes dual delivery protocols:
1. **HTML**: `https://adapt2.sis.pitt.edu/cupcake/#/activities/gillian-python/{filename}.yaml`
2. **SPLICE**: `https://adapt2.sis.pitt.edu/cupcake/#/activities/gillian-python/{filename}.yaml?protocol=splice`

## Scripts
- `port.py`: Fetches live activities and companion Python files from Cupcake and regenerates the JSON specifications.
- `push-to-catalog.py`: Ingests the items into the live SLC Catalog V2 with duplicate detection.
